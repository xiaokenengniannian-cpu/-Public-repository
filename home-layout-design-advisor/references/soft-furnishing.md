# 软装分析

## 判断框架

1. 先补住户画像与生活任务，再谈风格；同一户型会因家庭需求不同而产生不同答案（S01、S03）。
2. 先解决功能分区、动线、家具尺度与视线，再处理色彩、布艺、灯光和饰品（S02、S04）。
3. 家具先定位置与最大可接受体量，检查门窗、采光、空间纵深、开合、座椅拉出与搬运路径；缺实测不得给采购确定结论（S04）。
4. 色彩检查统一、变化、平衡、比例、焦点与呼应；这些是作者的视觉判断方法，不是规范（S05）。
5. 灯光按整体、局部、重点三层检查任务覆盖；电位、负荷、线路和施工由照明/电气专业复核（S06）。
6. 饰品按形、色、材、纹、尺度、受光检查，先控制焦点和数量（S07）。

## 建议写法

- 每条先写可见证据，再写条件性判断与低成本动作；涉及采购时列明需补的实测、样板、搬运和预算信息。
- 不输出无来源的家具尺寸、色温区间、材料性能或预算/市场价格。
- 效果图只证明设计意图，不证明尺寸、采购、施工或现场效果可行。
- 书中作者观点、经验建议与案例不可称为当前行业标准；页码与证据类型见 [source-index.md](source-index.md)。
