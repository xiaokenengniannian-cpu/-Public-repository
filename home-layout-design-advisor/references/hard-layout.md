# 硬装与户型分析

## 证据顺序

1. 分开记录 `[图示]`、`[用户提供]` 与未知项；依赖缺失条件的结论用 `[条件推断]`，需测量或专业确认的事项用 `[待核验]`。
2. 去掉房间名称暗示，按“谁—何时—做什么—从哪里进入—需要邻接什么”判断功能是否成立（H01）。
3. 用动作链叠加家具、门扇、抽屉、设备、人体与搬运包络；无可靠尺寸时只指出潜在冲突和实测项（H02）。
4. 把空间视为节点、门洞视为连线，查折返、穿越、孤立末梢、瓶颈与替代路径；回路不是自动优点（H03）。
5. 分角色检查公共/私密路径和沿途视线暴露，依据住户的互动与退避需求判断（H04）。
6. 展开早晚高峰，判断共享设施在被占用时是否形成并发瓶颈（H05）。
7. 对每个开口分别检查通行、视线、采光、通风目的及阻挡对象；缺朝向、遮挡、邻栋、窗型和现场风环境时不作精确结论（H06）。
8. 吊顶、地台、湿区、高差、门窗高度和设备隐藏必须进入剖面待核；平面放得下不等于可施工（H07）。
9. 比较方案时逐案写 GET、CUT、受益者、受损行为、可逆性与反转条件（H08）。

## 输出边界

- 不凭墙线粗细、照片或“允许改墙”确认承重、梁柱、楼板或开洞可行。
- 不把日本住宅案例、尺贯法或书中经验当作项目所在地现行标准。
- 结构、外立面、阳台荷载交结构工程师/建筑师/物业；燃气、给排水、电气、排烟排风交相应专业工程师；消防与规范问题交建筑师及当地合规审查角色。
- 所有方法与页码见 [source-index.md](source-index.md)。
