# 收纳与家务分析

## 根因顺序

按顺序检查：

`物品是否过量 → 使用点与收纳点是否错位 → 全屋大型收纳是否成立 → 柜内结构是否匹配 → 小容器与视觉是否需要优化`

厨房另按：`布局 → 橱柜 → 柜内收纳`。

## 执行要点

1. 柜、台面和地面同时满时，先查物品总量，不先加柜（ST01）。
2. 柜内有空而台面堆物时，先查使用点、开门与归位步骤（ST02）。
3. 户型图上检查各处是否就近收纳、零碎柜是否挤占活动面、连续墙面是否可形成集成收纳、藏露是否符合真实取用（ST03）。
4. 让住户口述真实流程，画动作节点与折返；无尺寸时只比较相对路线（ST02、ST04）。
5. 厨房画“取—洗—切—炒—盛”动作链，再谈布局；不把某一种布局当作无条件最优（ST05）。
6. 洗衣、清洁、晾晒与更衣按完整动作链检查；阳台给排水、防水、电位、荷载和外立面条件必须专业复核（ST04、ST06）。

## 边界

- 家庭人数、物品总量、使用频率与家务分工缺失时保持未知。
- 作者关于收纳占地、藏露关系或案例尺寸的建议只可作为有来源的经验参照，不得称强制规范；本报告默认不把它们转成数值建议。
- 固定柜、入墙柜、烟道、燃气、给排水、电气、阳台与防水仅给候选方向。
