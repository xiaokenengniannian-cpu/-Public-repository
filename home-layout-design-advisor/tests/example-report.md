# 住宅户型示例报告

## 图纸信息识别

- [图示] 可辨认客餐厅、卧室、厨房、卫生间及门窗关系；图中无可靠比例尺。
- [用户提供] 常住两名成人，偏好安静、易维护的居住方式。

## 信息缺失与待确认项

建筑面积、准确朝向、家庭未来变化、物品总量、预算、墙体性质、梁柱、管线、层高及墙体改动权限均未知。需补原始尺寸图、住户访谈和现场测量。

暂评 **58–72/100，可信度：低至中**。分项采用家庭适配/功能 25、动线/无障碍 20、采光/通风/隐私 20、收纳/家务 15、改造可行性/风险 10、软装/预算匹配 10；因关键数据缺失给区间。这是 Skill 合成量表，不是任何一本书的方法；风水贡献 0 分。

## 主要问题及优先级

- [图示]｜卧室门与客餐厅存在直接视线联系｜开门时可能暴露休息区｜若住户重视退避，先以家具或软隔断测试视线缓冲；实测后再定固定做法｜P1｜中｜H04｜室内设计师
- [待核验]｜图中墙体性质与管线不可确认｜任何开洞或湿区变化均不可直接落地｜仅保留候选方向，施工前完成结构与机电核验｜P0｜高｜H07｜结构工程师、给排水/电气工程师

## 硬装和空间改造建议

[条件推断] 若现状高频路径确有折返，可先通过改变家具和空间主次用途测试；只有测试证明有效且结构、消防、机电、物业均允许时，才深化门洞调整（H03、H08）。

## 动线、采光、通风及隐私分析

[图示] 可分析室内连接和潜在视线路径；因朝向、邻栋、遮挡、窗型与现场风环境未知，采光和通风暂不判断。补充资料后按开口四目的矩阵复核（H06）。

## 软装风格建议

[条件推断] 在“安静、易维护”目标下，可先统一大件的视觉关系，再用可替换织物形成受控变化；具体材质、家具体量与采购清单须结合实测、样板和预算确认（S04、S05）。

## 收纳规划建议

[待核验] 先盘点物品总量、使用频率与使用点；若台面堆物而柜内仍有空，优先减少开门与归位步骤，不先增加柜体（ST01、ST02）。

## 住宅风水文化建议

**传统文化参考**：准确朝向与中心点未知，暂不判断传统方位分类。该模块只作文化说明，零分；不预测健康、寿命、生育、财富、婚姻或见效时间，也不据此提出结构或高成本改造（F01、F02）。

## 风险、限制和专业复核事项

拆墙/开洞由结构工程师，燃气由燃气专业单位，消防与规范由建筑师及当地合规审查角色，给排水/电气/排风排烟由相应机电工程师，防水由防水专业，外立面与物业边界由建筑师/物业，阳台荷载由结构工程师复核。

## 方案A：低成本优化

先做住户访谈与物品盘点，用现有或可移动家具测试视线缓冲、路径和就近归位；优点是可逆，限制是不能解决经核实的结构性瓶颈。

## 方案B：完整改造

在实测、结构、机电、消防、物业和预算复核后，由设计师比较保留现状与调整入口/固定柜的 GET/CUT；专业闸门未通过前不进入施工结论。
