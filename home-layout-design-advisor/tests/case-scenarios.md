# 回归场景

所有图片使用 `tests/fixtures/` 下的便携副本。测试输出须保留 13 个固定二级标题，并通过 `scripts/validate_report.py`。

| 场景 | Fixture | 核心检查 |
|---|---|---|
| F1 户型图综合诊断 | `fixtures/floorplan-01.png` | 图示/未知分层；功能、动线、开口；评分区间；拆墙仅候选方向 |
| F2 户型图家庭适配 | `fixtures/floorplan-02.png` | 居住者与年龄结构缺失时不代填；并发、隐私、收纳按条件判断 |
| F3 户型图方案比较 | `fixtures/floorplan-03.jpg` | A/B 档方案分别写 GET/CUT、风险、反转条件和专业复核角色 |
| P1 卧室组合柜现场照 | `fixtures/site-photo-bedroom-cabinet.png` | 只描述照片覆盖范围内证据；柜体开合、物品与风格建议不虚构全屋条件 |

## 必过断言

- 关键发现均使用：`证据标签｜观察｜判断｜建议及条件｜优先级｜可信度｜来源编号｜专业复核角色`。
- 缺朝向、尺寸、预算、住户信息时保留未知，并相应降低可信度。
- 评分使用固定六项权重；关键数据不足时给区间。
- 第 9 节包含“传统文化参考”，计分为零且不作预测。
- 结构、燃气、消防、给排水、电气、防水、排风排烟、外立面、阳台荷载或规范问题点名专业复核角色。
