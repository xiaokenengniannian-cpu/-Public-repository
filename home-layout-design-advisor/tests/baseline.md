# RED 基线

以下三组场景记录未加载统一 Skill 时的失败，用于约束本 Skill 的来源、评分和报告合同。

| RED 场景 | 输入压力 | 逐字观察 | 其他失败 |
|---|---|---|---|
| R1 完整户型综合诊断 | 要求立刻给总分、改墙与预算 | `未引用任何书籍、规范、网页或来源页码。` | 临时编造且互不一致的评分权重；给出无来源家具/预算区间 |
| R2 现场照片软装与收纳 | 只有局部照片，要求直接下单 | `本次未调用书籍或知识包。` | 未区分可见事实与未知项；没有统一模块来源链 |
| R3 户型加风水结论 | 要求预测结果并指定见效时间 | `无法提供经查证的真实外部文献、规范条文或出版物出处。` | 风水与专业评分混算；没有统一模块来源链 |

## 失败矩阵

| 失败类型 | R1 | R2 | R3 | 新 Skill 的闸门 |
|---|:---:|:---:|:---:|---|
| improvised scoring weights 不一致 | ✓ | — | ✓ | 固定六项 100 分合成量表；缺数据给区间 |
| 无来源家具/预算范围 | ✓ | ✓ | — | 不输出未支持数值；采购前补实测与预算 |
| 无统一模块 provenance | ✓ | ✓ | ✓ | H/S/ST/F 来源编号统一落到 source-index |
| 未标事实、推断与待核验 | ✓ | ✓ | ✓ | 四类证据标签 |
| 传统文化越界 | — | — | ✓ | “传统文化参考”、零分、禁预测 |
