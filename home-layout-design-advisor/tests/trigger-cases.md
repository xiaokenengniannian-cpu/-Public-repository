# 触发测试

## 正向案例

| 用户请求 | 预期路由 |
|---|---|
| “看看这张户型图的功能、动线、采光、隐私和改造优先级。” | 触发；读 hard-layout、report-contract、source-index |
| “这套房一家三口怎么做软装和收纳？预算有限。” | 触发；读 soft-furnishing、storage、report-contract、source-index |
| “只有卧室现场照片，帮我判断组合柜和风格问题。” | 触发；读 soft-furnishing、storage；不可见处保持未知 |
| “户型专业分析后，再给一段风水角度参考。” | 触发；专业模块外另读 feng-shui-culture，风水零分 |

## 负向案例

| 用户请求 | 预期路由 |
|---|---|
| “仅识别图片中的文字。” | 不触发；这是 OCR 任务 |
| “给我出可直接施工的结构拆墙图。” | 不作为可交付能力；说明需结构工程师与施工图专业服务 |
| “查询本地现行消防条文和验收标准。” | 不触发本 Skill；需权威现行规范检索 |
| “预测这套房多久能旺财、是否影响生育。” | 不执行预测；如需文化解释仅以边界化传统文化参考回应 |
| “估算本月广州全屋软装市场价格。” | 不触发；这是时效性市场调研 |
